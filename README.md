# GRMEngine 

A C++ Game Engine designed primarily for 2D games (at the moment).

## ✏️ About
GRMEngine is a project solo developed by me to learn C++ and more about how computers actually work.

GRM stands for **G**raphics, **R**endering, **M**ath. Of course I think the Engine part of it is pretty easy to understand what it is.

----

## 🚀 Features (In Progress)

- [ ] **Math Library:** Custom `Vec2`, `Vec3`, `Vec4`, and `Mat4` implementations.
- [ ] **GAL (Graphics Abstraction Layer):** Support for OpenGL. (Later Vulkan)
- [ ] **ECS (Entity Component System):** ECS system for 
- [ ] **Renderer:** Batch rendering and sprite management.
- [ ] **Input System:** Keyboard and mouse support.

## ⌨️ Setup

#### Prerequisites

* **CMake**
* **C++ 20 compiler** 

#### Source

1. **Configure CMake**  
   Generate the build system:
    ```bash
    cmake -B build
    ```

2. **Build the Project**  
   Compile the source code:
    ```bash
    cmake --build build
    ```

3. **Run Executable**  
   Run the built file:
    ```bash
    ./build/GRMEngine
    ```
